# The Last Library Light

ITE 270 Capstone Assignment 1. Seven scenes, 317 script words, one planned choice and two endings.

Adapted from the instructor's story-template.zip. The .scene / .video-wrap / .scrim / .panel structure, full-screen video presentation, IntersectionObserver-driven playback and text reveals, mute, pause and progress-dot pattern come from the starter. Orchestration was revised to keep exactly one active video, preserve visible text without JavaScript and honor reduced motion.

Practice footage (including its sound) is temporary and instructor-provided, not student-created library footage. Each source clip is eight seconds. Scenes 4–7 reuse the supplied clips as allowed in Tutorial 1.

Both endings are deliberately visible in the linear scroll for Assignment 1. The interactive branch and three story-reveal buttons are planned for Assignment 3. Original sound, narration, media, a 3D shot and added scroll effects are planned for Assignment 2.

Start muted. Scroll or use the named scene dots. Pause All stops all videos and transitions. Keyboard users can Tab to every control. Reduced motion holds the posters until the viewer chooses Play scene.

Do not claim the later-assignment features are complete. See ASSET_LOG.md and PROMPT_LOG.md for provenance.
